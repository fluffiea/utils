## @fluffiea/utils

A collection of commonly used JavaScript methods.

## Installation

`npm:`

```bash
npm install @fluffiea/utils
```

`pnpm:`

```bash
pnpm add @fluffiea/utils
```

## Usage

`ESM:`

```ts
import { getType } from '@fluffiea/utils'

const value = '0327'
console.log(getType(value)) // out >> String
```

`CommonJS`

```ts
const { getType } from '@fluffiea/utils'

const value = '0327'
console.log(getType(value)) // out >> String
```
