# isNumber

判断数据是否为`number` 类型

## 引入

```ts
import { isNumber } from '@fluffiea/utils'
```

## 使用

```ts
import { isNumber } from '@fluffiea/utils'

isNumber(value)
```

## 参数

| 属性名   | 类型      | 描述           |
| -------- | --------- | -------------- |
| `value`  | `unknown` | 需要判断的类型 |
| `return` | `boolean` |                |
