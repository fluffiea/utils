# isString

判断数据是否为`string` 类型

## 引入

```ts
import { isString } from '@fluffiea/utils'
```

## 使用

```ts
import { isString } from '@fluffiea/utils'

isString(value)
```

## 参数

```ts
/**
 * @param value
 * @returns
 * @since 0.0.1
 */
```



| 属性名    | 类型      | 描述           |
| --------- | --------- | -------------- |
| `value`   | `unknown` | 需要判断的类型 |
| `returns` | `boolean` |                |
